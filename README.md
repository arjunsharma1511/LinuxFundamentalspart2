# Linux Field Notes | Fundamentals Part 2

An independent beginner exercise with 28 MCQ-gated terminal commands, six final questions and a flag hunt. The browser simulates the Cedar Library workstation, including its files, remote session and permission changes.

Open `index.html` locally. To use GitHub Pages, place these files together in your Pages publishing folder or one of its subfolders.

- `index.html`
- `styles.css`
- `lessons.js`
- `simulator.js`
- `app.js`
- `WALKTHROUGH.txt`

The walkthrough contains answers to the questions and the route to the flag. The final flag value is recovered in the terminal.
